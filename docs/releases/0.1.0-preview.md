# Preview notes — v0.1.0-preview.1

**An early local workspace for source-led film restoration and human comparison.** The complete conventional FFmpeg workflow works without model weights. Actual LTX model inference remains unverified in this preview.

The preview tag identifies a prerelease of the initial `0.1.0` source tree; Python/frontend package versions remain `0.1.0`. A preview tag is not a stable inference-capability claim. See [Releases](https://github.com/jdj333/ltx-reference-restorer/releases) for published versions. Follow the [setup guide](../setup.md) from a source checkout. On macOS, the included `Launch Restorer.command` opens the launcher; terminal users can run `./scripts/launch.sh`.

## Included

- First-use setup/status view with actionable tool/worker/backend checks, an in-app synthetic demo and safe diagnostics.
- Scoped local video/image browsing, visual reference cropping and unsaved shot-setup guards.
- Actor reference libraries with explicit approval, provenance and native-size crops.
- Shot selection, manual face placement and inspection of the actual guide artifact.
- Real FFmpeg baseline upscaling, frame/audio checks, immutable job versions, scoped cancellation and retry.
- Exact server-decoded source/output PNG stills while paused, mapped to the completed job's frozen frame records, with explicit loading/failure states. Play switches to synchronized browser video; side-by-side/overlay, face regions, references and human review remain available.
- Reproducible recipes and safe reports for three official Library of Congress YouTube editions, with 49-frame clips and held-out source references. Downloads remain opt-in and outside Git.
- Pinned ComfyUI Restore/Refine graph contracts, explicit backend blockers and a controlled baseline/B/C evaluation procedure.
- Chromium/WebKit regression suite with isolated generated media, keyboard/dialog checks and comparison/reopen coverage.
- Source-checkout launcher, setup/contribution and privacy-conscious reporting guidance, public-film screenshots and a dated verification history.

## Evidence and limits

Current local validation passed **124 Python tests** in 31.84 seconds, the strict TypeScript/Vite build, and **6 Chromium/WebKit browser cases** in 30.7 seconds. Browser checks use the real isolated API/worker and FFmpeg, inspect actual decoded PNG pairs and face-crop pixels, and cover loading/failure/retry, final-frame replay and anamorphic display through pause/play. Exact-revision scope and remote CI are recorded separately in [verification](../verification.md) and [Actions](https://github.com/jdj333/ltx-reference-restorer/actions). All three public-film baseline workflows passed again, retaining 49 frames each with zero measured timestamp/duration discrepancy; the [fresh safe report](../../fixtures/public-films/results/2026-10-21-polish.json) records those actual jobs. See [public-film results](../public-film-results.md) for measurements and source attribution.

Paused inspection uses exact decoded PNG pairs rather than relying on browser video seek painting. A request that cannot be verified or decoded produces an explicit failure; loading does not certify the requested frame. Playing remains synchronized browser video for motion review and does not promise frame-accurate browser presentation on every platform.

The inspected local ComfyUI endpoint was unavailable, and required LTX nodes and model files were absent. **No B/C inference, GPU-memory benchmark or human identity/performance approval is reported.** MLX restoration/reference rendering is unavailable. The first conditioning contract permits one actor, one approved reference and static placement on a short progressive CFR shot; it does not implement native simultaneous multi-reference identity conditioning.

Tested end-user platform: macOS arm64. Ubuntu CI verifies automated Python/FFmpeg and frontend checks. Native Windows is unsupported. Downloaded films, generated videos, app databases, model weights and credentials are excluded from tracked source. Public fixtures/media and model terms retain their own scope; see their linked source/model records.
