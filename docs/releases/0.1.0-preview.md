# Draft preview notes — proposed v0.1.0-preview.1

**An early local workspace for source-led film restoration and human comparison.** The complete conventional FFmpeg workflow works without model weights. Actual LTX model inference remains unverified in this preview.

**Publication status: draft; no preview tag or release has been published for this work. The code-license choice is pending.** The proposed tag would identify a prerelease of the initial `0.1.0` source tree; Python/frontend package versions remain `0.1.0`. A preview tag is not a stable inference-capability claim. Follow the [setup guide](../setup.md) from a source checkout. On macOS, the included `Launch Restorer.command` opens the launcher; terminal users can run `./scripts/launch.sh`.

## Included

- First-use setup/status view with actionable tool/worker/backend checks, an in-app synthetic demo and safe diagnostics.
- Scoped local video/image browsing, visual reference cropping and unsaved shot-setup guards.
- Actor reference libraries with explicit approval, provenance and native-size crops.
- Shot selection, manual face placement and inspection of the actual guide artifact.
- Real FFmpeg baseline upscaling, frame/audio checks, immutable job versions, scoped cancellation and retry.
- Synchronized side-by-side/overlay comparison, face regions, reference display and persisted human review.
- Reproducible recipes and safe reports for three official Library of Congress YouTube editions, with 49-frame clips and held-out source references. Downloads remain opt-in and outside Git.
- Pinned ComfyUI Restore/Refine graph contracts, explicit backend blockers and a controlled baseline/B/C evaluation procedure.
- Chromium/WebKit regression suite with isolated generated media, keyboard/dialog checks and comparison/reopen coverage.
- Source-checkout launcher, setup/contribution and privacy-conscious reporting guidance, public-film screenshots and a dated verification history.

## Evidence and limits

Current local polish validation passed **120 Python tests** in 25.71 seconds, the strict TypeScript/Vite production build and **6 browser cases** in 17.0 seconds. The three scenarios ran in both Chromium and WebKit against the real isolated API/worker and FFmpeg, including reference approval/guide/render, diagnostics, playback/keyboard comparison, review/reopen, unsaved-save guards and project-draft isolation. All three public-film baseline workflows passed again, retaining 49 frames each with zero measured timestamp/duration discrepancy; the [fresh safe report](../../fixtures/public-films/results/2026-10-21-polish.json) records the actual jobs. Historical GitHub Actions runs passed; the expanded Python 3.11/3.14 and Chromium/WebKit CI configuration has [results attached to each pushed commit](https://github.com/jdj333/ltx-reference-restorer/actions). These local measurements do not assert a remote CI result. See [verification](../verification.md) for exact revisions, executed checks and platform scope, and [public-film results](../public-film-results.md) for measurements and source attribution.

The inspected local ComfyUI endpoint was unavailable, and required LTX nodes and model files were absent. **No B/C inference, GPU-memory benchmark or human identity/performance approval is reported.** MLX restoration/reference rendering is unavailable. The first conditioning contract permits one actor, one approved reference and static placement on a short progressive CFR shot; it does not implement native simultaneous multi-reference identity conditioning.

Tested end-user platform: macOS arm64. Ubuntu CI verifies automated Python/FFmpeg and frontend checks. Native Windows is unsupported. Downloaded films, generated videos, app databases, model weights and credentials are excluded from tracked source. Public fixtures/media and model terms retain their own scope; see their linked source/model records. This draft does not select or grant a code license, and it does not grant model or media rights.
